# Styles and vibes

Night garden arcade, one palette, every cabinet.

- Void `#070A08`, pit `#0C1410` / `#101A14`, leaf `#3DDC84`, head `#C8FF7A`, bite `#FF5A6A`. Moss, dew, shell, vein, pond, sky are sprite inks only.
- Characters are garden creatures, not triangles: snake beads, frog, moth-bird, crab invaders, beetle craft, sprouts with eyes.
- Icons use the same sprites as the pits.
- Cabinet cards are dark pads with a leaf stroke on press. No ripple ink.
- Live games start from a pit hint, never a full-screen overlay that steals the first touch.
- Sprites and hitboxes share one size. Fingers steer from the first touch.
- Type is loud on titles, mono on scores, quiet on blurbs.
- Scrollbars, if any, are a leaf thumb on void. Never default gray.
