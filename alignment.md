# Alignment

- Menu is an app-icon grid, 3 across: glyph, short title, tiny score. Not a name-only list. Hot-seat games caption as "hot seat".
- Scores picks a game by icon, not truncated name chips.
- Every game keeps the same HUD: back + title left, value + pause right.
- Boards sit in a rounded pit. Overlays dim the pit only, never the HUD.
- Stacks: full-width pit; next / rotate / drop sit in one row under the board, never a side rail.
- High-score name field is a pit-colored outline, leaf stroke, 12 characters.
- Saved names sit as tap chips above the field so a name can be reused without retyping.
- Scores screen: TOP 3 podium, then full HISTORY under it.
- Leaderboard chips share one row; mines adds a second row for Easy / Med / Hard.
- If a list scrolls, a leaf thumb sits on the void track.
- Status bar matches the void. Navigation bars hide; swipe them back if needed.
- Live cabinets use a bottom pit hint, not a dim overlay, so the first finger still plays.
- Hits use the same size as the sprite. Paddles, baskets, birds, crabs, and stones collide with what you see.
- Action fires on finger-down. Swipe games use one gesture: a tap or a swipe, not both.
- Rocks: hold toward a point to fly, tap to fire.
- Dodge and Catch: finger-follow. Hop: tap hops up, swipe sidesteps.
- Snake, Pong, and Memory open with Solo / Hot seat. Pong is two paddles on one pit. Memory takes turns. Snake is a run, then pass.
